🧪 Automação de Testes Web | Java + Selenium

Tricentis Demo Web Shop

**Status:** Em desenvolvimento  
**Tipo:** Automação de testes funcionais  
**Aplicação:** [Tricentis Demo Web Shop](https://demowebshop.tricentis.com/)

🎯 Objetivo

Este projeto tem como objetivo desenvolver uma automação de testes funcionais para uma aplicação de e-commerce, utilizando Java e Selenium WebDriver.

A proposta é automatizar os principais fluxos da aplicação, validando o comportamento das funcionalidades e garantindo que os resultados estejam de acordo com os requisitos esperados.

🔍 Escopo da automação

A automação será desenvolvida de forma incremental, contemplando inicialmente o processo de registro de usuários e posteriormente outros fluxos da aplicação.

**Funcionalidades previstas:**

- Registro de usuários.
- Autenticação e login.
- Pesquisa e seleção de produtos.
- Gerenciamento do carrinho de compras.
- Processo de checkout.


🛠️ Tecnologias utilizadas

- Java
- Selenium WebDriver
- Maven
- TestNG
- Git e GitHub


🏗️ Estrutura e boas práticas

O projeto buscará aplicar boas práticas de automação de testes, incluindo:

- Page Object Model (POM).
- Reutilização de componentes.
- Organização dos scripts de teste.
- Centralização de configurações.
- Tratamento de exceções.
- Separação entre páginas, dados e testes.


▶️ Execução do projeto

A automação utiliza Java, Selenium WebDriver e Maven para a execução de testes funcionais em uma aplicação de e-commerce.

Os testes poderão ser executados localmente, após a configuração do ambiente e das dependências necessárias.

O projeto contará também com integração contínua (CI) por meio do GitHub Actions, possibilitando a execução automatizada dos testes a cada atualização do repositório.


📊 Resultados

Os resultados serão disponibilizados por meio de relatórios de execução gerados automaticamente, permitindo acompanhar:
- Total de testes executados.
- Testes aprovados e reprovados.
- Evidências de execução.
- Falhas identificadas durante a automação.
Os relatórios e as evidências serão publicados como artefatos das execuções do GitHub Actions.
